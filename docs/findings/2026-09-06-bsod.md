## Why the cloak can BugCheck

`MpBypassInstallIntegrityCloak` (called from every RA neutralize) wrote a **14-byte `FF 25` abs-jmp** on process-global:

- `vcruntime140!memmove`
- `vcruntime140!memcpy` (already `E9` — 5-byte tail jmp; **9 extra bytes overwrite the next CRT export**)
- `ucrtbase!memmove`

Copy path used `ntdll!RtlMoveMemory`. NVIDIA UMD (`nvwgf2umx`) uses the same CRT. First GPU AV was ~1 s after the D3D12 hook **and** the CRT splice — **before** any Relic integrity splice log. Overlay then kept Present-skipping for 162 faults instead of unhooking. Kernel VidMm could not recover → `0x10E`.

PAGE_GUARD / KiUser / Relic IAT / all-thread DRx were **not** armed. Not CE `dbk64` / DBVM (no such driver after reboot; cloak was the live change).
