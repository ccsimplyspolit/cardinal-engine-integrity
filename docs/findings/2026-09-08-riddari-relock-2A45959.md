## Finding

This is the documented think crash in `AI_UNIT_CONTROL.md`:

`AI_LockSquad` after `AI_Enable` on a squad that already has a tracking
object and `[obj+0x40]==0` takes **4A70** (strip tactics). The next Relic
think tick does `mov ecx, [rax+58h]` with `rax=0`.

`L.safe` / `SafeStrip` means *tracked + idle stack*, not *safe to lock*.
That is the 4A70 row in the native table, not 4CE0.

`kRelockTryCap` had drifted back to **16**. After a real lock, RPM often
still reads `SafeStrip`, so the pass kept walking the next L.safe sids.
Four `LockOneSid` in 20 ms matches that loop. 09-07 set the cap to 1 for
the same blast radius (FPS + 4A70).

Riddari / Hippodrome dummy cav carry `scar_scout` (live PBG). Making them
`isArmy` so standing scan (AI off, 4CE0) gives them to the player is
correct. Feeding the same leaves to `LockOneSid` after Enable puts Relic
`scoutPlans` through 4A70.

50291 / 50325 stayed `skip-eco` all match (Lua still saw them as eco on
the injected build). The 03:03 burst is the first time this session
`LockOneSid` treated a cluster as army + SafeStrip.
