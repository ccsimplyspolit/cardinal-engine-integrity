# RelicCardinal struct field offsets — build 16.3.11308.0

Generated by `tools/build_struct_offsets.py` from the injector sources.
These are offsets **into game structures**, not module RVAs — they carry
no signature and `resolve_offsets.py` cannot re-find them. When a patch
changes a struct layout the owning RVA still resolves but the field moves,
so this is the **manual checklist**: re-verify each against a fresh dump
(the comment is the hint). Many are also cross-checked at runtime by the
injector (a field must point at something sane). See `docs/OFFSETS_UPDATE.md`.
